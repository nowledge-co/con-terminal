Setup

Add this repository

{{if .Signing.Enabled}}
1 Add the signed remote (flatpak ≥ 1.17)
flatpak remote-add --user \ --signature-lookaside={{.PagesURL}}/{{.Signing.Lookaside}} \ {{.RemoteName}} \ {{.PagesURL}}/{{.RemoteName}}.flatpakrepo

The .flatpakrepo file configures the remote and imports the public GPG key automatically.

2 Install con terminal

Select a release channel below or install via terminal command.

Download .flatpakrepo View OCI index Public key

For older graphical clients, signature verification needs to be configured manually after setup:

flatpak remote-modify --user \ --signature-lookaside={{.PagesURL}}/{{.Signing.Lookaside}} \ {{.RemoteName}}
{{else}}
1 Add the remote (unsigned)
flatpak remote-add --if-not-exists --user --no-gpg-verify \ {{.RemoteName}} \ oci+{{.PagesURL}}
