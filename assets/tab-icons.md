# Tab Identity Icons

The current local preview uses `tab-terminal-refined.png` for terminal
identities: a front-facing teal frame with a dark screen and broad ivory prompt,
without a stand or perspective tilt. The built-in image tool generated it on
2026-10-13 as an edit of the maintainer's framed reference: reduce rim thickness,
enlarge the prompt, reduce glossy highlights and retain shallow dimensionality.
Transparent surroundings have no external shadow or glow. Earlier terminal
variants are retained for comparison; the other five identities are unchanged.

## Approved Terminal Prompt

Tool: built-in image generation, transparent background. Edit reference: the
maintainer's teal framed terminal image. The packaged asset is downsampled to
256 pixels; runtime previews use the existing physical-size cache.

```text
Edit the supplied terminal icon, preserving its front-facing rounded-square
silhouette, teal palette, dark teal inner screen and warm ivory >_ prompt.
It will be displayed at only 16 points in a desktop tab. Refine rather than
reinvent. Reduce the thick inflated turquoise outer frame to about HALF its
current thickness, expand the dark inner screen correspondingly, keep smoothly
rounded corners with radius about25% of object width. Enlarge the >_ prompt to
occupy about65% of the inner screen width, with generous clean spacing, balanced
centred placement, use crisp smooth consistent rounded strokes. Make the
material refined satin rather than wet glossy plastic: remove sweeping glare
and strong specular streaks, keep only a subtle upper edge highlight and shallow
bevel indicating depth. Reduce the extrusion of the prompt, almost flat ivory
with a very small chamfer; no deep shadows behind it. Moderate the bright aqua
to a tasteful clear turquoise, retain enough color life at small sizes. Clean
deliberate broad masses and optical balance, no tiny details. NO stand, NO base,
NO monitor legs, NO perspective tilt, NO extra objects, NO external shadow,
NO halo or glow. Truly transparent surrounding canvas, clean alpha edge without
stray speckles. Object fills86% of a square canvas, centred. One icon only.
High-end modern restrained 3D icon, less toy-like, more legible at tiny sizes.
Do not turn it into a flat single-color pictogram.
```

For new members of the framed family, reuse the approved terminal image as the
style reference, preserving viewpoint, corner radius, rim thickness, shading
and optical scale. Change only the role symbol and a restrained role color.
Inspect at 16 points in both themes before accepting it; a large source image
does not establish small-size quality.

`tab-terminal.png`, `tab-code.png`, `tab-file.png`, `tab-remote.png`,
`tab-monitor.png`, and `tab-reader.png` were generated for Con
on 2026-10-13 at the maintainer's request. They are original generic identities,
not replacements for application or provider logos.

The visual brief is six freestanding miniature objects, with no shared square
backplate: a teal prompt, amber code brackets, a folded amber document, teal
connection loops, three teal monitor columns, and an ivory open book. Broad
silhouettes and shallow chamfers keep the objects legible at sixteen points.
There are no external shadows or glows. Negative spaces and the surrounding
canvas are transparent. Each packaged source is 256 pixels square; Con
downsamples and caches it for the actual display scale and UI size.

Use these only for tab identities. Close, action and program-status controls
continue to use the existing Phosphor assets. Keep the same bitmap in the
resting tab and its drag preview, and preserve semantic status overlays.
