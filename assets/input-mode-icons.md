# Input Mode Icons

These assets identify the three input modes. They are not submit, stop or
approval controls; those remain theme-colored Phosphor SVGs.

- Smart: `input-mode-smart.png`, amber wand and sparkle.
- Shell: `tab-terminal-refined.png`, the approved teal terminal identity.
- Agent: `input-mode-agent.png`, blue conversation bubble.

Generated with the built-in image tool on 2026-10-13. Both new assets use
`tab-terminal-refined.png` as the edit/style reference, transparent output,
256-pixel packaged sources and the shared physical-size preview cache.
The mode button is 28 points with a 24-point image canvas; transparent inset
keeps the visible object around 20 points. Do not add a second resting frame.

## Smart Prompt

```text
Edit the supplied image as a style reference for a sibling tiny desktop input mode icon. Preserve its front-facing rounded-square silhouette, 25% corner radius, thin satin rim, dark inset face, restrained shallow 3D depth and optical scale. Change the terminal symbol to a very simple ivory diagonal magic wand with ONE large four-point sparkle near its upper right, no tiny stars or dots. Change the teal frame to tasteful warm honey amber and the dark screen to deep warm brown. The symbol must be clean broad geometry, almost flat with a small chamfer, large enough to remain clear at20points. Frame takes about8% of width, symbol about65% of inner face width. Reduce strong glossy streaks, no wet plastic, no neon, no external glow, no cast shadow, no base or stand, no perspective. Object fills86% of square canvas, truly transparent surroundings with clean alpha. One icon only. This is Smart mode for a terminal input bar, not a game reward or toy. Match the reference's crafted family and retain enough color for light and dark UI.
```
