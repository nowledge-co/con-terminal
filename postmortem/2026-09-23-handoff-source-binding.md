# Handoff 在来源 Agent 退出后才允许点击

## 发生了什么

测试版要求用户先退出来源 Agent 及后台命令，再点击 Handoff。这样终端前台已回到 Shell，窗口无法直接证明当前原生 session；目录内的旧会话可能被误选。

## 根因

UI 把“停止当前工作”误实现成“退出 Agent TUI”，并用 Tab 缓存的最后一个 Agent 品牌识别来源。该缓存只适合显示图标，不是会话身份。

## 修复

点击 Handoff 时要求来源 TUI 正在运行，记录 Tab、terminal、前台进程组、Agent 类型和目录；只查询该 Agent 在该目录的会话。唯一候选显示 ID 并要求用户确认它是当前会话，多候选强制用户选择。弹窗内确认当前 turn 与后台命令已停止；发送前再次核对来源绑定。Shell Tab 不能发起新交接。

## 学到什么

“停止写入”和“退出进程”是不同状态。先绑定运行中的进程，再等待用户停止工作，才能保留来源身份；原生会话 ID 未由终端直接暴露时，不能用最近更新时间猜测。
