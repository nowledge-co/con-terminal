# Handoff 审查后续修复

## What happened

会话复核把检查失败显示为会话切换；首次绑定失败没有面板提示。安装缓存使新装 CLI
最多五分钟不可见。被移除 Agent 的旧任务无法加载，租约仍保留但用户难以处理。

## Root cause

绑定 Result 被压成 Option；面板使用后台 TTL 缓存；持久化枚举没有未知变体。
DimAgent（后续已移除；此处为历史事实） 的来源版本限制和独立目标能力也缺乏清楚的界面区分。

## Fix applied

区分复核失败和会话变化，均 fail-closed；首次识别失败显示手动确认提示。
面板打开刷新 inventory，保留后台缓存。未知 Agent 允许读取旧任务但拒绝读来源、启动和投递，
保留原状态及租约，继续通过现有取消/确认停止流程释放。分别展示来源与目标能力。
拆分 reserve/delivery 模块，记录 macOS-only 的运行时和 CI 边界。

## What we learned

无法识别旧 Agent 不证明目标已停止，不能自动 Failed 并释放租约。
能力状态与诊断须区分来源和目标；缓存失效应贴合用户重新打开面板的动作。
